Twenty cloud browsers open at once. Each carries a different person — a different screen, a different country, a different reason for showing up. Watch them all at the same time, then read where every one of them gave up.

Lena, Eleanor, and Haruto browse from Germany, the UK, and Japan.
A run takes ~35s and costs ~50¢ — of which the twenty browsers are about 1¢.

One run per code. It runs on our keys — you never see them, and you pay nothing.

Keys are used for this run only and never stored on the server.

Only point this at sites you own or public marketing pages. The strangers read, scroll, and follow links — they never buy, submit, or send anything.

The cast

Twenty people chosen so their failures don't overlap. Between them they cover findability, mobile layout, consent banners, keyboard access, jargon, and the dead ends people hit when they need a human.
